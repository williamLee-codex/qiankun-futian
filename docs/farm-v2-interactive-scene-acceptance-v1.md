# 乾坤福田 V2｜2D 即時互動農場場景驗收 V1

## 本階段目標
玩家在同一農場場景中直接點擊六塊農田完成播種及收成。靈獸與農夫只需靜態上陣展示。手機觸控優先。所有成功動畫必須以後端確認成功為依據，不得虛構庫存或收成。

## 必須交付的互動
1. **空田播種**：點擊已解鎖的空田，從已選定的種子或合理預設種子決定播種內容；檢查倉庫庫存及後端授權。成功後種子從倉庫沿弧線飛向目標田；失敗時顯示原因，不能播放成功動畫。
2. **生長外觀**：至少五種視覺狀態（播種／幼苗／成長／近成熟／成熟），按伺服器的生長起訖時間推導；重新整理、離線回來仍一致。不可僅替換計時器文字。
3. **成熟收成**：點擊成熟作物，後端成功後作物從農田飛入倉庫，數量同步增加，農田回到空地；重複點擊不得重複入庫。
4. **靜態角色**：上陣靈獸及農夫以靜態立繪呈現在場景中，不攔截農田觸控；本階段不做角色移動、巡邏及 AI。
5. **座標與效能**：單一共用六田錨點來源供 hotspot、作物與飛行動畫使用；手機 320/390px、平板及桌機驗收；觸控不誤觸，尊重 reduced-motion。
6. **資料權威**：農場前端只能做即時視覺回饋，種子扣除、收成入庫、解鎖及成熟時間均由正式後端確認；網路失敗可回復，避免重複操作。

## 驗收案例
- A：空田有種子 → 單擊 → 倉庫飛種 → 農田播種成功。
- B：空田缺種子 → 單擊 → 明確提示，庫存與農田不變。
- C：鎖定田 → 單擊 → 顯示解鎖條件，不扣種子。
- D：生長中 → 重整／等待 → 正確生長階段及倒數，不可提前收成。
- E：成熟 → 單擊 → 作物飛倉庫、數量正確；雙擊及重試不重複收成。
- F：Core 或 Farm API 失敗 → 不顯示成功、不丟失資料。
- G：靈獸與農夫靜態展示，且六田均可觸控。
- H：不同尺寸及 reduced-motion 下視覺可用。

## 施工順序
先追查 GameContext / API 接線，確保不是只有本機模擬；再統一農田座標與動畫來源；接著實作播種飛行、多階段作物、靜態農夫與靈獸；最後集中跑單元、整合及手機 E2E。避免每一小改動都觸發昂貴的部署。
