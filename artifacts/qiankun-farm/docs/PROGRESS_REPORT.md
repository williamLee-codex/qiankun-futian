# 乾坤福田 V2 Progress Report

_文件建立日期：2026-07-09。本文件僅記錄現況，不涉及任何功能異動。_

## 1. P0 已完成項目

- 六塊靈田完整解鎖流程（金幣解鎖第2、3塊；累積儲值解鎖第4～6塊）
- 播種／收成／出售基礎迴圈，各作物 1:1 固定產出比例
- 一鍵收成、一鍵播種、一鍵收播、智慧收播（含種子不足補購確認視窗）
- 靈寵系統：凡品／靈品／仙品／神品四級，出戰、餵食、冷卻機制
- 農夫系統：累積儲值滿額解鎖，玩家自行開關，不強制接管
- 福田每日任務（獎勵僅限金幣，與御策羅盤「天機」系統獨立）
- 天氣系統（晴／雨／雷／雪，影響生長速度與偷吃機率）
- 天道律法說明頁（完整規則文件化於遊戲內）

## 2. 好友福田 V1.1 已完成項目

- 移除福田專屬好友身份資料結構（`farmFriends` / `farmFriendRequests` 已不存在）
- 好友身份資料改由平台級模組 `src/platform`（`platformFriends` / `platformFriendRequests` / `platformUserProfile`）提供，欄位僅限 UID、暱稱、頭像、最後上線時間、是否公開、福田是否公開
- 福田端僅保留與平台好友「互動」相關的 `borrowState`（因果鎖印冷卻、各田成熟狀態），以平台 UID 為索引鍵，不含任何身份資料
- 好友頁（FriendsPanel）改為讀取 `usePlatformFriends()`，新增好友會寫入平台好友資料，而非福田自有資料
- 新增／實作借運（`VISIT_BORROW`）與一鍵採收（`HARVEST_ALL_FRIEND`）兩個獨立 action

## 3. 借運規則

- 系統從好友第 2～5 塊「合法成熟田」中隨機選取 1 塊（第 1、6 塊不可借運）
- 訪客取得該田可借運作物數量的 20%，無條件進位，至少 1 個
- 地主損失同等數量（模擬對象，非本地玩家資產）
- 每次借運扣除當日借運次數（預設每日 10 次，中午 12:00 重置）
- 借運後對該好友建立獨立 24 小時因果鎖印冷卻

## 4. 一鍵採收規則

- 只處理成熟超過 1 小時未收（超時）的作物，一次處理所有符合條件的超時田
- 訪客取得超時作物總量的 5%，無條件進位，至少 1 個
- 地主取得剩餘 95%，歸還地主倉庫
- 一鍵採收不是借運：不扣每日借運次數、不建立因果鎖印

## 5. 靈寵影響

- 借運：有效。仙品靈獸「噬時諦聽」出戰時，有機率額外觸發一次借運收益
- 一鍵採收：不受靈寵借運效果影響，收益固定為總量 5%

## 6. 資料儲存現況

- 目前所有遊戲狀態（含好友互動狀態、平台好友示範資料）皆為前端 MVP 版本，儲存於瀏覽器 `localStorage`
- 平台好友（`platformFriends`）目前為前端模擬（mock）資料，尚未串接御策羅盤主程式真實好友 API

## 7. 資料庫變更聲明

- 本階段所有工作僅涉及 `artifacts/qiankun-farm` 前端程式碼
- 未修改任何資料庫結構、未觸碰 Supabase、未執行任何 migration
